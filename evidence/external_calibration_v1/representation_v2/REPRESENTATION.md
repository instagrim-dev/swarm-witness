# Frozen-slice representation study

This is a frozen-slice representation study of the existing 70-packet eligibility set. All 70 identifiers are inside the earlier 130-packet EvidenceGraph event corpus, so the slice is not unseen and this is not an independent held-out validation.

Raw classifiers recover 0/36 assessor-decisive labels. With the shared admitted-premise adapter, both composed arms recover 36/36. Derived records are transformations: the composed arms still count 332 supplied records as the independent sources and make 0 further requests.

Against the separate warrant, the composed arms have 10 unsupported supports. Those are the retained false-exclusivity packets. Matching the assessor is composition fidelity, because the assessor and the adapter share premise logic. It is not independent correctness. `external_empirical_transfer` is not_tested. The retained `transfer_claim` flag records that scope limit. `superiority_claim` and `independent_jury` stay false.

The historical refutation nominee remains the lexicographically first fabricated claim, and its assessor label is unresolved. A supplementary refuted row is an inspected representative selected from the retained labels, not a blind validation case.

Removing the successful control's registry mutation returns the assessor label to unresolved. Duplicating that record, or adding an irrelevant record, does not create a new assessor label.
